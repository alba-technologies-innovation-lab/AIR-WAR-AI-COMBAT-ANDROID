## Le jeu

**AIR WAR — AI COMBAT** est un jeu mobile de simulation militaire en 3D, développé sous **Unity** pour les téléphones et tablettes **Android en mode paysage**.

Incarnez un pilote, explorez plusieurs îles, déplacez-vous à pied, prenez le volant d'un véhicule militaire, pilotez des avions et accomplissez des missions aériennes. Le jeu évolue au fil du développement : certaines fonctionnalités sont encore expérimentales ou incomplètes.

## Fonctionnalités du projet

- **Campagne 3D** : îles, océan, bases aériennes et déplacements libres.
- **Pilotage aérien** : avions à débloquer, décollage, vol, missions et retour à la base.
- **Véhicules** : conduite de 4×4 militaires et interactions au sol.
- **Hangar** : sélection, personnalisation et amélioration des équipements et des avions.
- **Missions** : combat aérien, interception, escorte, défense et protection.
- **Météo et cycle jour/nuit** : systèmes en cours de développement et d'intégration.
- **Multijoueur** : fonctionnalités prévues et en développement ; disponibilité non garantie dans les versions de test.

Ces éléments décrivent le projet et sa feuille de route, pas une garantie que chaque fonction soit opérationnelle dans le prochain APK.

## Télécharger la bêta Android

**Aucun APK n'est publié pour le moment.** Le téléchargement sera disponible lorsque le développeur aura ajouté une version testée dans la section **Releases**.

1. Ouvrir [**la page des versions**](https://github.com/alba-technologies-innovation-lab/AIR-WAR-AI-COMBAT-ANDROID/releases).
2. Sélectionner la version bêta souhaitée.
3. Dans **Assets**, télécharger le fichier `.apk` fourni par le développeur.
4. Sur Android, ouvrir le fichier téléchargé et, si nécessaire, autoriser temporairement l'installation depuis cette source.
5. Après l'installation, désactiver l'autorisation d'installation depuis cette source si vous ne l'utilisez plus.

**Important :** vérifiez que le fichier provient bien de ce dépôt officiel. N'installez pas d'APK provenant d'une source inconnue ou d'un lien non vérifié.

Les versions de test peuvent présenter des problèmes de performance, des interfaces incomplètes, des erreurs de gameplay, des bugs graphiques, des interruptions ou une perte de progression. La compatibilité peut varier selon les téléphones Android. Une connexion peut être nécessaire pour certaines fonctions.

Si vous testez le jeu, merci de transmettre :

- le modèle du téléphone et la version Android ;
- le numéro de version du jeu ;
- les étapes exactes pour reproduire le problème ;
- une capture d'écran ou une courte vidéo, si possible.

Vous pouvez signaler les problèmes dans [**Issues**](https://github.com/alba-technologies-innovation-lab/AIR-WAR-AI-COMBAT-ANDROID/issues) sans communiquer de données personnelles ou sensibles.
